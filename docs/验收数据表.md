## 三、辨识并改变电机 ID（验收项③）

**辨识**：上电后看电机指示灯——**绿灯每秒闪 N 次 = ID = N**。

**改变**（演示一次即可，例如把 ID1 改成 ID2）：

1. 断电
2. 拨码开关 Bit0~2 拨成 `010`（=2）：Bit0=OFF，Bit1=ON，Bit2=OFF
3. 上电 → **绿灯应每秒闪 2 次**
4. 改 `Inc/board_config.h`：`#define MOTOR_ID (2u)` → 重新编译下载
5. 串口应显示 `motor ID=2, feedback ID=0x206, ctrl ID=0x1FF`，`online=1`
6. 演示完改回 ID1（或保持 2，代码同步即可）

**对应关系表**（写报告用）：

| 拨码 Bit[2:0] | 001 | 010 | 011 | 100 | 101 | 110 | 111 |
|---|---|---|---|---|---|---|---|
| 电机 ID | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
| 反馈标识符 | 0x205 | 0x206 | 0x207 | 0x208 | 0x209 | 0x20A | 0x20B |

## 四、用 Debug 查看角度/速度（验收项⑤明确要求）

1. Keil 点 **Debug**（不要先 Download，程序已在跑就用 `Debug → Start/Stop Debug Session`）
2. 全速运行（F5）
3. `View → Watch Windows → Watch 1`，添加两个变量：
   - `g_motor` → 展开看 `angleRaw`、`angleDeg`、`angleCont`、`speed`、`currentA`、`tempC`
   - `g_ctrl` → 展开看 `mode`、`out`、`pidSpeed.Kp/Ki/Kd`、`pidAngle.Kp/Ki/Kd`
4. **用手转电机**，Watch 里的 `angleDeg` / `angleCont` / `speed` 会实时变化 → **截图**

> 这就是"通过 debug 查看电机回传的角度、速度"的验收证据。

## 六、讲解口径（30 秒版）

> 我用 CAN1 以 1Mbps 驱动 GM6020：CAN 中断只把报文入队，1ms 的 `Task_MotorCtrl`
> 做解析和双环 PID（位置环出速度目标并限速，速度环出电压），5ms 的 Task_Log 用
> JustFloat 把目标/实际/输出打成曲线。PID 是独立的 `pid.c/h` 库，速度环和位置环
> 各是一个实例，参数全部通过串口在线修改，所以整轮调参没有重新编译一次。
> 速度目标从 1000rpm 降到 100rpm，是因为 GM6020 手册标称最高 320rpm。
