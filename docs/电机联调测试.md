# GM6020 联调测试（期望现象 + 判定标准）

> 固件：`MDK-ARM/gimbal/gimbal.hex`（25MHz 外部晶振版）
> 串口：PC12(TX)/PD2(RX)，**115200 8N1**，接 USB-TTL
> 电机：24V 供电，CAN 线（红=CANH，黑=CANL），**电机必须固定**
> 拨码：Bit0~2 = ID（本工程默认 **ID=1**，反馈帧 0x205）；第 4 位 ON = 接入 120Ω 终端电阻

---

## 0. 上电自检（先看这几行）

正常应看到：

```
==== GM6020 CAN demo (F405 + FreeRTOS) ====
clock source : HSE 25000000 Hz          ← 关键：必须是 HSE 25MHz
SYSCLK=168000000 HCLK=168000000 PCLK1=42000000 PCLK2=84000000
CAN1: NORMAL baud=1000000 bps (prescaler=3, TQ=14)
motor ID=1, feedback ID=0x205, ctrl ID=0x1FF
send 'help' for commands
```

| 打印项 | 正确值 | 不对怎么办 |
|---|---|---|
| `clock source` | `HSE 25000000 Hz` | 若显示 `HSI(fallback)` = 晶振没起振，检查 X1 |
| `SYSCLK` | 168000000 | — |
| `PCLK1` | 42000000 | CAN 波特率靠它 |
| `baud` | **1000000** | 不是 1Mbps 就收不到电机数据 |

## 1. 读反馈（验收项⑤）

上电后每 500ms 一行：

```
mode=0 online=1 rx=1853 ang=214.7 cont=214.7 spd=0 cur=0.02A tmp=32C out=0
```

| 字段 | 含义 | 期望 |
|---|---|---|
| `online` | 是否收到反馈 | **1**（0 = 没收到，见排查表） |
| `rx` | 累计收到帧数 | **持续增加**，1 秒约 +1000（电机 1kHz 反馈） |
| `ang` | 单圈机械角 0~360° | 手转电机时**跟着变** |
| `cont` | 连续角度（多圈累计） | 手转多圈时**超过 360 继续涨** |
| `spd` | 转速 rpm | 静止时 ≈0，手转时有正负值 |
| `tmp` | 电机温度 ℃ | 室温 ~30℃，长时间大负载会升到 50~80℃ |
| `out` | 当前输出电压 | 上电是 0 |

**Debug 查看（验收要求）**：Keil Debug 全速运行 → `View → Watch Windows` 添加：
- `g_motor` → 展开看 `angleRaw / angleCont / speed / currentA / tempC`
- `g_ctrl` → 展开看 `mode / out / pidSpeed.Kp ...`

## 2. 电机指示灯（验收项③：辨识 ID）

| 现象 | 含义 |
|---|---|
| **绿灯每秒闪 N 次** | 正常，**ID = N** |
| 橙灯每秒闪 2 次 | 总线上有重复 ID → 改拨码 |
| 红灯每秒闪 1 次 | 供电电压过高 |
| 红灯每秒闪 4 次 | 温度过高（>125℃），已关输出 |

**改 ID 验证**：断电 → 拨码改 Bit0~2（如改成 010 = ID2）→ 上电看绿灯闪 2 次 →
把 `Inc/board_config.h` 的 `MOTOR_ID` 改成 2 → 重新编译 → 串口应显示 `feedback ID=0x206`。

## 3. 让电机转起来（验收项④）

```
v 2000      → 电机缓慢正转（CCW），串口 out=2000
v -2000     → 反向转（CW）
v 5000      → 明显加快
stop        → 立即停止，out=0
```

| 期望 | 说明 |
|---|---|
| `v 2000` 后电机**匀速缓转** | 电压模式是开环，转速随负载变化 |
| `v -2000` **反向** | 从输出轴看：正电压 = CCW |
| `stop` 后**立即停** | 输出 0，电机有轻微阻尼 |
| 输出限幅 | 默认 ±6000，`lv 12000` 可放大（最大 25000） |

⚠️ 若 `v 2000` 电机不转：先加到 `v 5000` 试试（有静摩擦），仍不转看排查表。

## 4. 速度环（验收项⑥）

```
sp 100      → 目标 100 rpm（GM6020 上限 320rpm，任务书 1000rpm 做不到）
log 1       → 开曲线（VOFA 选 JustFloat）
```

**VOFA 会看到 4 条曲线**：`ch0=目标` `ch1=实际` `ch2=输出` `ch3=误差`

期望：
- 实际速度**快速上升**到 100 附近
- `kp` 太小 → 上得慢、稳不住在 100（有稳态误差）
- `kp` 太大 → 冲过头（超调）+ 抖动
- 加 `ki` → 稳态误差消失，但过大会超调

**调参方法（不重新编译）**：
```
kp 40      改速度环 Kp
ki 3       改速度环 Ki
log 0      回文本模式看数值
```

**记录阶跃指标**（验收要写）：

| 指标 | 怎么从曲线读 |
|---|---|
| 超调量 | `(峰值转速 - 100) / 100 × 100%` |
| 响应时间 | 从发命令到进入 98~102 rpm 并稳住的时间 |
| 稳态误差 | 稳定后 `|实际 - 100|` |

## 5. 位置环双环（验收项⑦）

```
an 180      → 相对当前位置转 180°
an 720      → 转两圈（验证多圈）
zero        → 当前角度清零
```

期望：
- 电机**快速转过去然后停住**，不来回摆动
- `an 720` 能连续转两圈停在正确位置（误差 <1°）
- 位置环输出被限速（`g_ctrl.speedCmd` 不超过 `ls` 设的 250rpm）

**必须先调好速度环再调位置环**：
```
kp2 1.2    位置环 Kp（决定"多快冲过去"）
kd2 0.03   位置环 Kd（抑制超调）
```

## 6. 保护测试（安全必须验证）

| 操作 | 期望 |
|---|---|
| 拔掉 CAN 线 | 串口 `online=0`，**电机立即停止出力**（1ms 内） |
| `stop` | 立即停，PID 积分清零 |
| 重新上电 | 默认 IDLE 不输出，不会飞车 |

## 7. 排查表

| 现象 | 原因 | 处理 |
|---|---|---|
| `online=0`、`rx` 不涨 | 没收到反馈帧 | ①24V 供电 ②CANH/CANL 是否反 ③终端电阻（量 CANH-CANL≈60Ω）④ID 是否为 1 |
| `baud` 不是 1000000 | 时钟不对 | 串口看 PCLK1 是否 42000000 |
| 灯不亮 | 没供电 | 量电机 XT30 是否 24V |
| 绿灯闪但 `online=0` | ID 不符 | 数灯确认 ID，改 `MOTOR_ID` |
| 橙灯闪 2 次 | 重复 ID | 改拨码 |
| `v 5000` 不转 | 静摩擦/限幅 | `lv 12000` 再 `v 8000`；仍不转检查相线（GM6020 一体化，多半是供电） |
| 速度环抖动 | Kp 过大 | 减小 `kp`，加一点 `kd` |
| 一直差一点到不了目标 | 缺积分 | 加 `ki`（0.5 起步） |
| 位置环冲过头 | Kp2 大 / Kd2 小 | 减小 `kp2` 或加大 `kd2` |
| 串口乱码 | 波特率不对 | 必须是 115200 |

## 8. 原理图上的其它可用资源（后续阶段用）

| 资源 | 引脚 |
|---|---|
| CAN2 | PB12(RX) / PB13(TX) |
| IMU（BMI088 / ICM42688） | SPI1：PA5=SCLK，PA6=MISO，PA7=MOSI |
| USART1 / USART2 / USART6 | PA9/PA10、PA2/PA3、PC6/PC7 |
| I2C1 | PB6=SCL，PB7=SDA |
| USB | PA11/PA12（**与 CAN1 复用，用 CAN 时不能同时用 USB**） |
| 32.768kHz RTC 晶振 | PC14/PC15（位号 Y2） |
| BOOT0 / BOOT1 | 均有 10K 下拉到 GND（默认正常启动） |
