# VOFA+ 快捷调参设置（把 kp/sp 等做成按钮和滑条）

> 目标：在 VOFA+ 里做出一排**按钮**（一键发 `sp 100`、`stop` 等）和一排**滑条**
> （拖动实时改 `kp`、`ki`……），调参不再手敲命令。
> 固件解析按"空白分词 + 空闲中断分帧"，**命令结尾不需要换行符**，直接发文本即可。

---

## 一、原理（30 秒）

VOFA+ 的**命令** = 一段文本（如 `kp %%`）+ 绑定的**控件**（Button/Slider）。
`%%` 是占位符，会被控件的当前值（按钮的参数 / 滑条的数值）替换后从串口发出。

固件端（`uart_vofa.c` + `app_tasks.c`）靠**串口空闲中断**分帧、按空白分词解析，
所以：
- 命令**不需要**`\r\n` 结尾（发了也行）
- JustFloat 波形和命令发送**互不干扰**（波形照常显示，命令框照常发）

---

## 二、操作步骤

### 1. 新建命令
1. VOFA+ 左侧/菜单进入 **控制（控件）** 页面
2. 找到 **命令** 列表 → **新建命令**
3. 填写：
   - **名称**：随便起（如 `kp滑条`、`stop按钮`）
   - **数据类型**：选 **Text / 文本**（不要选 Hex！）
   - **发送内容**：如 `kp %%`、`sp 100`
   - `%%` = 绑定控件的参数占位符（按钮控件会填它设置的事件参数；滑条会填当前值）

### 2. 放控件并绑定
1. 从控件库拖一个 **Button** 到面板 → 属性里关联命令（如 `stop`），点击即发送
2. 拖一个 **Slider（滑条）** → 属性设置：
   - **最小/最大值**：见下面推荐表（如 Kp：0 ~ 60）
   - **步进/精度**：Kp 取整数步进；kd2 这类小参数把小数位设 2~3 位
   - **关联命令**：选 `kp %%` 对应的命令
3. 拖动滑条 → 串口立刻发出 `kp 35.00` → 固件立刻生效（波形上马上能看到变化）

## 三、推荐配置表（照着配一遍就能用）

### 按钮（一键发送）

| 按钮 | 发送内容 | 用途 |
|---|---|---|
| 停止 | `stop` | 紧急停 + 清积分 |
| 速度0 | `sp 0` | 速度目标回零（阶跃前先归零） |
| 阶跃100 | `sp 100` | 速度环阶跃 |
| 转180 | `an 180` | 位置环阶跃 |
| 转720 | `an 720` | 多圈测试 |
| 清零角度 | `zero` | 当前位置设为 0° |
| 遥控开 | `rc 1` | 允许遥控控制 |
| 遥控关 | `rc 0` | 禁止遥控 |
| 曲线开 | `log 1` | 切 JustFloat（配波形用） |
| 曲线关 | `log 0` | 切回文本（看数值） |
| IMU自检 | `imust` | 重跑 BMI088 自检 |

### 滑条（拖动实时发）

| 滑条 | 发送内容 | 范围 | 步进/小数位 |
|---|---|---|---|
| Kp | `kp %%` | 0 ~ 60 | 整数 |
| Ki | `ki %%` | 0 ~ 10 | 0.1 |
| Kd | `kd %%` | 0 ~ 5 | 0.01 |
| Kp2（位置环） | `kp2 %%` | 0 ~ 5 | 0.01 |
| Ki2 | `ki2 %%` | 0 ~ 0.2 | 0.005 |
| Kd2 | `kd2 %%` | 0 ~ 0.2 | 0.005 |
| 限速 ls | `ls %%` | 0 ~ 320 | 整数 |
| 限压 lv | `lv %%` | 0 ~ 25000 | 100 |
| 爬行 lmin | `lmin %%` | 0 ~ 50 | 整数 |
| 遥控死区 dz | `dz %%` | 0 ~ 0.3 | 0.01 |

> 滑条小数位在控件属性里设（"小数位数/精度"）。
> `dz %%` 这类小数参数，滑条值会替换 `%%` 后发出（如 `dz 0.15`），固件的 `atof` 能正常解析。

---

## 四、注意

1. **数据类型必须选 Text**——选 Hex 会把字符当字节发，固件解析不了
2. 波形（JustFloat）与命令发送**互不影响**：一个页面里既看波形又放控件，
   就是阶段二验收视频里"上面波形 + 下面调参"的效果
3. 滑条拖动会**连续发送**（拖一下发几十条），固件解析是幂等的，没有副作用；
   若觉得刷屏，把滑条改成"按钮+数值输入框"的组合
4. 调乱了：点"停止"按钮 → 按 `docs/PID调参指南.md` 第五节一键复位

## 五、验收演示建议（面试加分）

调参环节直接用这套：**一边拖滑条改 kp，一边指着 VOFA 波形说"可以看到超调在变大"**——
参数、波形、结论三者实时联动，比"改代码→编译→烧录→再看"的流程有说服力得多。
