# 联调测试：期望现象 + 逐步验收（SBUS 版）

> 固件：`MDK-ARM\stage3\stage3.hex`（2026-09-08 编译，0 Error / 0 Warning）
> 当前配置：`RC_PROTOCOL = 1`（SBUS/DBUS，USART2/PA3，P1 座 DBUS 下层）
> 串口看日志：**UART5 = PC12(TX) / PD2(RX)，115200**
> 前提：遥控器与接收机**已对码成功**，接收机输出模式 = **S.BUS**

---

## 一、上电串口应该看到什么（按顺序）

```
==== GM6020 CAN demo (F405 + FreeRTOS) ====
clock source : HSE 25000000 Hz                 ← 必须是 HSE 25MHz
SYSCLK=168000000 HCLK=168000000 PCLK1=42000000 PCLK2=84000000
CAN1: NORMAL baud=1000000 bps (prescaler=3, TQ=14)
motor ID=1, feedback ID=0x205, ctrl ID=0x1FF
send 'help' for commands

BMI088 self-test:                               ← IMU 自检（任务书要求）
  acc  CHIP_ID = 0x1E (expect 0x1E) : OK
  gyro CHIP_ID = 0x0F (expect 0x0F) : OK
  gyro self-test reg = 0x02 : OK
  acc magnitude = 1.0xx g (expect ~1.0, keep still) : OK
BMI088 self-test PASSED
```

之后两种日志交替（各 500ms 一行）：

```
mode=0 online=1 rx=18539 ang=217.7 cont=-73.2 spd=0 cur=0.15A tmp=28C out=0 | can lec=0 tec=0 rec=0 boff=0
imu: acc[ 0.02 -0.01  1.01]g gyro[  0.10  -0.20   0.05]dps temp=31.5C n=123
```

| 字段 | 期望 | 不对怎么办 |
|---|---|---|
| `online` | 1 | 0 = 没收到电机反馈：查 24V、CANH/CANL、终端电阻、ID |
| `rx` | 每秒 **+1000**（电机 1kHz） | 不涨 = CAN 没通 |
| `acc[2]`（板子平放） | ≈ **1.0 g** | 差太多 = 板子没放平，或 BMI088 SPI 异常 |
| `gyro` 静止 | **< ±1 °/s** | 大 = 板子在动或零偏未处理 |
| `tmp` | 室温 ~30℃ | — |

⚠️ 自检时**板子必须放平且别动**（自检会检查加速度模长是否≈1g）。

## 二、遥控数据是否收到（Keil Debug 看）

Debug → F5 跑起来 → **勾上 `View → Periodic Window Update`** → Watch 1 添加 `g_rc`：

| 字段 | 期望 |
|---|---|
| `frameCount` | **持续增长**，SBUS 约每 7ms 一帧 → **每秒 ~140** |
| `linked` | **1** |
| `failsafe` | **0**（关遥控后变 1 → 立即停机） |
| `ch[0]`、`ch[1]`（CH1/CH2） | 1000~2000 之间，**动摇杆时跟着变**，松手回 ~1500（DBUS 回 1024） |
| `ch[2]`（油门 CH3） | 推左手上下时变化 |

`frameCount` 不动 = 遥控器没连上或输出模式不是 S.BUS，见文末排查表。

## 三、验收测试项（逐项打勾）

### ✅ 测试 1：遥控控制 DJI 电机（验收项 1）

```
rc 1              ← 串口命令：开启遥控控制（默认关闭）
```

| 操作 | 期望现象 |
|---|---|
| 右摇杆**向上推**（CH2） | 电机**正向转**（CCW），推得越多越快（最大 ±250rpm） |
| 右摇杆**向下拉** | 电机**反向转**（CW） |
| 摇杆**回中** | 电机**停止**（有 5% 死区，中位附近不动） |
| 推到底 | 接近 250rpm（受 `ls` 限速） |

可选安全开关（用 SwA 拨杆做使能）：
```
rsw 5       ← CH5 作为使能开关：拨到上位（>中位）才允许输出
rsw 0       ← 取消
```

### ✅ 测试 2：遥控保护 —— 关遥控电机立即没力（验收项 2）

| 操作 | 期望现象 |
|---|---|
| **关掉遥控器电源** | ① 串口打印 `[RC] link lost -> motor disabled` ② **电机立即失去动力**（手能轻松转动） |
| 观察 `g_rc.failsafe` | 变 **1**（若接收机设了 Failsafe，帧里会带失控标志 → 立即判失联） |
| 重新开遥控器 | 自动恢复；摇杆可继续控制 |
| **拔掉 SBUS 信号线** | 同上，立即停机（100ms 内） |
| 拔掉电机 CAN 线 | 另一路保护：`online=0` → 立即停输出 |

**为什么"没力"**：保护触发后 ① 切 `MODE_IDLE` ② 清 PID 积分 ③ 发 **0 电压**，
电机不再有驱动力矩（自由状态），而不是"保持上次转速"。

### ✅ 测试 3：IMU 自检与数据（验收项 3）

| 操作 | 期望 |
|---|---|
| 上电 | 串口打印 4 行自检，最后 `BMI088 self-test PASSED` |
| 串口发 `imust` | 重新跑一次自检（板子放平后重测） |
| 平放看 `acc[2]` | ≈ 1.0g |
| 倾斜板子 | `acc[0]/acc[1]` 随倾斜变化 |
| 转动板子 | `gyro` 出现 ±几十 °/s |

### ✅ 测试 4：阶段二功能回归（都在同一个工程里）

| 命令 | 期望 |
|---|---|
| `sp 100` | 速度环：电机加速到 100rpm 稳住 |
| `an 180` | 位置环：转 180° 停住 |
| `an 720` | 多圈：连续转两圈停在 720°±1° |
| `log 1` | 切 JustFloat 曲线（VOFA 选 JustFloat 协议） |
| `stop` | 停止输出 |

## 四、10 分钟完整验收流程（照着做）

1. 烧 `MDK-ARM\stage3\stage3.hex`
2. 串口打开（PC12，115200）→ 看启动信息 + **BMI088 self-test PASSED**
3. 电机 24V 上电 → 看 `online=1`、`rx` 每秒 +1000
4. 接收机接 P1 座下层 DBUS（S/+/−），遥控器开机
5. Debug 看 `g_rc.frameCount` 每秒涨 ~140、`ch[]` 随摇杆变
6. 串口发 `rc 1` → 推右摇杆 → **电机转**
7. **关遥控** → 电机立即没力 + 串口 `link lost`
8. 重开遥控 → `sp 100` / `an 180` / `an 720` 回归测试

## 五、排查表

| 现象 | 检查 |
|---|---|
| `frameCount` 不涨 | ①接的是 P1 座**下层 DBUS**（不是上层舵机）②接收机 Output Mode = **S.BUS** ③对码成功（红灯常亮）④GND 共地 |
| 通道值乱/全是 0 或 2047 | 波特率/格式不对（应 100000 8E2）；或把 iBus（正逻辑）接到已反相的 P1 座 |
| 电机不转（遥控有数据） | 发 `rc 1` 没？`rsw` 开关没拨到位？`ls` 限速太小（试试 `ls 250`）？ |
| 关遥控电机还转 | 看串口有没有 `link lost`；检查 `RC_LINK_TIMEOUT_MS`（100ms） |
| BMI088 自检 FAIL | 看哪一行 FAIL；CHIP_ID 失败 = SPI/片选问题（CS_Accel=PC4、CS_Gyro=PA4） |
| 加速度模长 ≠1g | 板子没放平/在晃，放平后发 `imust` 重测 |
| 串口乱码 | 波特率不是 115200，或 `HSE_VALUE` 又变回 8MHz（应为 25000000） |
