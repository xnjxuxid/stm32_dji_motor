# 串口命令与输出说明（完整参考）

> 串口：**UART5 = PC12(TX) / PD2(RX)，115200 8N1**（接 USB-TTL，看日志/发命令）
> 发命令：串口助手/VOFA 文本窗口输入命令 + 回车；发 `help` 可随时查看命令表

---

## 一、控制模式（理解输出的前提）

```
MODE_IDLE  (0)   不输出任何电压（上电默认 / stop 后 / 保护触发）
MODE_VOLT  (1)   直接给电压（开环，试转用）
MODE_SPEED (2)   速度环：目标 rpm
MODE_ANGLE (3)   位置+速度双环：目标角度（连续角度，支持多圈）
```

---

## 二、命令表

### 电机控制

| 命令 | 含义 | 备注 |
|---|---|---|
| `v <volt>` | 电压模式，直接给电压 | 范围受 `lv` 限幅；先小后大（2000 起步） |
| `sp <rpm>` | 速度环目标 | GM6020 上限 320rpm，本工程限 ±250 |
| `an <deg>` | 位置环：**相对当前**转多少度 | 支持多圈（`an 720`）；自动清 PID |
| `stop` | 停止输出，回 IDLE，清积分 | 安全命令 |

### PID 参数（改完立刻生效，不用重新编译）

| 命令 | 参数 | 作用 | 经验范围 |
|---|---|---|---|
| `kp <v>` | 速度环 Kp | 追速度的力度 | 20~60 |
| `ki <v>` | 速度环 Ki | 消速度稳态误差 | 1~5 |
| `kd <v>` | 速度环 Kd | 速度环一般不用 | 0 |
| `kp2 <v>` | 位置环 Kp | 多快冲过去 | 0.8~3 |
| `ki2 <v>` | 位置环 Ki | 治末端爬行 | 0.01~0.05 |
| `kd2 <v>` | 位置环 Kd | 抑制超调 | 0.02~0.08 |

### 限幅与死区

| 命令 | 含义 | 默认 |
|---|---|---|
| `lv <volt>` | 输出电压限幅（安全上限） | 6000（最大 25000） |
| `ls <rpm>` | 内环速度限幅（位置环时电机的"最高限速"） | 250（GM6020 上限 320） |
| `lmin <rpm>` | 位置环最小速度（治末端爬行） | 15 |
| `ad <deg>` | 位置环到达死区（误差小于它算到位） | 0.5 |
| `dz <0~0.5>` | **遥控死区**（归一化）：松手回中误差的容忍度，残余速度就加大 | 0.10 |

### 遥控（阶段三）

| 命令 | 含义 | 默认 |
|---|---|---|
| `rc 1` / `rc 0` | 允许/禁止遥控控制电机 | **0**（上电必须先开） |
| `rsw <ch>` | 安全开关通道号（1~14）：该通道 > 中位才允许输出 | 0 = 不用开关 |
| `rch` | （已弃用，CH2 固定为速度通道） | — |
| `dz` | 同上，遥控死区 | 0.10 |

### IMU 与其它

| 命令 | 含义 |
|---|---|
| `imust` | 重新跑一遍 BMI088 自检（板子放平再发） |
| `zero` | 把当前位置设为角度零点 |
| `log 1` / `log 0` | 切 JustFloat 曲线 / 文本日志（两者互斥，都会打） |
| `help` | 命令表 |

## 三、串口输出逐字段解读

### 1) 电机状态行（500ms 一条，文本模式）

```
mode=0 online=1 rx=18539 ang=217.7 cont=-73.2 spd=0 cur=0.15A tmp=28C out=0 | can lec=0 tec=0 rec=0 boff=0
```

| 字段 | 含义 | 正常值 |
|---|---|---|
| `mode` | 控制模式 0~3 | 0=IDLE 1=VOLT 2=SPEED 3=ANGLE |
| `online` | 电机 CAN 在线 | **1**（0 = 没收到反馈） |
| `rx` | 累计收到反馈帧数 | **每秒 +1000**（电机 1kHz 反馈） |
| `ang` | 单圈机械角 0~360° | 手转时变化 |
| `cont` | 连续角度（多圈累计） | 正转增加、反转减少，可超 ±360 |
| `spd` | 转速 rpm | 正=CCW（从输出轴看） |
| `cur` | 实际转矩电流 A | ±3A 满量程；堵转会大 |
| `tmp` | 电机温度 ℃ | 室温~80℃，>100 警告 |
| `out` | 当前输出电压 | 受 `lv` 限幅 |
| **`can lec`** | CAN 最后错误码 | **0 = 正常**；**3 = ACK 错**（总线上没人应答 → 电机没上电/线没接） |
| `can tec` | 发送错误计数 | 0~255；>128 进入错误被动 |
| `can rec` | 接收错误计数 | 正常 0 |
| `can boff` | Bus-Off 标志 | 1 = 总线关闭（持续无应答），接线后自动恢复 |

### 2) 遥控状态行（500ms 一条）

```
rc: link=1 fs=0 fc=4546 ch=[1024 1006 1085 1024] sw=0
```

| 字段 | 含义 | 正常值 |
|---|---|---|
| `link` | 遥控链路状态 | **1** = 收到 SBUS 数据 |
| `fs` | SBUS 失控标志 | **0**；1 = 接收机进入失控保护（立即停机） |
| `fc` | 累计 SBUS 帧数 | **每秒 ~130~140**（7ms 一帧） |
| `ch[n]` | 通道原始值 | **中位 1024**，范围 364~1684（FlySky S.BUS 量纲，实测） |
| `sw` | 当前安全开关通道号 | 0 = 未启用 |

**判读**：
- `fc` 不涨 → 没收到 SBUS（查接线/Output Mode/对码）
- `fc` 涨但 `ch` 不随摇杆变 → 接错了口（接到舵机 PWM 口了）
- `ch` 乱跳 → 帧错位（当前固件已用帧头同步修复）
- 摇杆回中 `ch` 偏离 1024 很多 → 遥控器做一次摇杆校准，或加大 `dz`

### 3) IMU 状态行（500ms 一条）

```
imu: acc[-0.25 -0.28 0.96]g gyro[0.1 -0.2 0.05]dps temp=29.6C n=3601
```

| 字段 | 含义 | 正常值 |
|---|---|---|
| `acc[0..2]` | 三轴加速度（g） | 平放 z≈**+1.0**，x/y≈0；倾斜时按姿态分布 |
| `gyro[0..2]` | 三轴角速度（°/s） | 静止 **< ±1**，转动时 ±几百 |
| `temp` | 芯片温度 ℃ | 接近室温 |
| `n` | 累计读取次数 | 每秒 +100（10ms 读取） |

### 4) 保护提示

| 打印 | 含义 |
|---|---|
| `[RC] link lost -> motor disabled` | **遥控失联**：已切 IDLE + 清积分 + 发 0 电压（电机没力）。恢复遥控后自动解除 |
| `note: got feedback from ID 0x20X -> set MOTOR_ID=n` | 收到了别的 ID 电机的反馈：把 `MOTOR_ID` 改成提示的 n |
| `sensor data saturated/locked - recovering` | 原始数据满量程锁死（罕见），自动恢复中 |

## 四、VOFA 曲线通道含义（`log 1` 时，协议选 JustFloat）

| 通道 | 含义 |
|---|---|
| ch0 | 当前模式的目标值（速度 rpm / 角度 ° / 电压） |
| ch1 | 实际值（速度 rpm / 连续角度 °） |
| ch2 | PID 输出（电压） |
| ch3 | 误差（目标 − 实际） |

**阶跃测试读指标**（`sp 100` 或 `an 180` 后看 ch1 曲线）：

| 指标 | 读法 |
|---|---|
| 超调量 | (峰值 − 目标) / 目标 × 100% |
| 响应时间 | 阶跃起 → 进入目标 ±2% 且不再出来 |
| 稳态误差 | 稳定后 \|实际 − 目标\| |

> JustFloat 帧是二进制的，**和文本日志互斥**（`log 1` 时文本行停止），避免互相干扰解析。

## 五、标准调参流程（速查）

```
1. 速度环（内环）
   rc 0            关遥控，用串口控制
   sp 0            回零
   kp 30  ki 2  kd 0
   sp 100          阶跃，看曲线
   不理想按 docs/PID调参指南.md 第三节的"现象→处方"调

2. 位置环（外环）
   zero
   kp2 1.5  ki2 0.02  kd2 0.03
   lmin 15  ad 0.5
   an 180          阶跃
   an 720          多圈验证

3. 遥控接管
   rc 1            开遥控
   dz 0.10         残余速度就加大
   rsw 5           可选：SwA 通道做安全开关

4. 调乱了
   stop  然后按上面步骤重设
```
