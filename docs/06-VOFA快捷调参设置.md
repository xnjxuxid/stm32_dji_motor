# VOFA+ 快捷调参设置（把 kp/sp 等做成按钮和滑条）

> 目标：在 VOFA+ 里做出一排**按钮**（一键发 `sp 100`、`stop` 等）和一排**滑条**
> （拖动实时改 `kp`、`ki`……），调参不再手敲命令。
> 固件解析按"空白分词 + 空闲中断分帧"，**命令结尾不需要换行符**，直接发文本即可。

---

## 一、原理（30 秒，以官方文档为准）

VOFA+ 的命令分两种模式（**我们用 Str 模式**）：

| 模式 | 占位符 | 发出形式 |
|---|---|---|
| **Str 模式** | **`%d` / `%f`**（printf 风格） | ASCII 文本（如 `rc 1`） |
| Hex 模式 | `%%` | 原始字节流 |

- 命令里写占位符 → 绑定控件 → 控件的**当前值/状态参数**替换占位符后发出
- **开关类控件**：右键 →"发送参数"可以设置**抬起/按下**两个状态各自的参数
  （如按下=1、抬起=0 → 配 `rc %d` 就是"点一下开、再点关"的切换开关）
- 固件端（`uart_vofa.c` + `app_tasks.c`）靠**串口空闲中断**分帧、按空白分词解析，
  所以命令结尾带不带 `\n` 都能识别；JustFloat 波形与命令发送互不干扰

---

## 二、操作步骤

### 1. 新建命令
1. VOFA+ **左边栏 → 命令** → 添加新命令
2. 填写：
   - **名称**：随便起（如 `遥控开关`、`Kp滑条`、`停止`）
   - **模式**：选 **Str（ASCII 文本）**（不要选 Hex！）
   - **内容**：如 `rc %d`、`kp %f`、`stop`
   - 占位符会被控件参数替换（`%d` 整数、`%f` 浮点）

### 2. 切换开关（rc / log 这种"点一下开、再点关"）★你问的这个
1. 控件库拖 **Toggle 类按钮**（如 `ExtraButton Toggle`，两态按钮）到控制面板
2. **右键控件 → 绑定命令** → 选 `rc %d`（Str 模式）
3. **右键控件 → 发送参数**：
   - **按下（开）状态参数 = 1**
   - **抬起（关）状态参数 = 0**
4. 效果：点击开关 → 发 `rc 1`；再点 → 发 `rc 0`。命令里写 `%d` 发出整数。

按同样方法再做：
- `log %d`：按下=1（切 JustFloat 曲线）、抬起=0（切回文本）
- 想要"按住才有力、松手立刻没力"的按压式保护按钮：普通 Button 绑 `rc %d`，
  按下=1、抬起=0，天然就是点动开关

### 3. 滑条（连续调参）
1. 拖 **Slider** → 属性设置最小/最大值与小数位（见推荐表）
2. 右键绑定 Str 模式命令（如 `kp %f`，用 `%f` 保留小数）
3. 拖动滑条 → 串口实时发出 `kp 35.00` → 立刻生效

### 4. 普通按钮（固定内容）
拖 **Button** → 绑定一条**不含占位符**的命令（如 `stop`、`sp 100`）→ 点击即发

## 三、推荐配置表（照着配一遍就能用）

### 按钮（一键发送，普通 Button 绑固定内容）

| 按钮 | 发送内容 | 用途 |
|---|---|---|
| 停止 | `stop` | 紧急停 + 清积分 |
| 速度0 | `sp 0` | 速度目标回零（阶跃前先归零） |
| 阶跃100 | `sp 100` | 速度环阶跃 |
| 转180 | `an 180` | 位置环阶跃 |
| 转720 | `an 720` | 多圈测试 |
| 清零角度 | `zero` | 当前位置设为 0° |
| IMU自检 | `imust` | 重跑 BMI088 自检 |

### 切换开关（Toggle 两态按钮 + 发送参数）

| 开关 | 命令（Str 模式） | 按下参数 | 抬起参数 | 效果 |
|---|---|---|---|---|
| 遥控使能 | `rc %d` | 1 | 0 | 点一下开遥控、再点关 |
| 曲线/文本 | `log %d` | 1 | 0 | 切 JustFloat 曲线 / 文本日志 |
| 点动保护（可选） | `rc %d`（普通按钮，按下=1 抬起=0） | 1 | 0 | **按住才有力，松手立即没力**——天然的保护演示按钮 |

### 滑条（拖动实时发）

| 滑条 | 发送内容 | 范围 | 步进/小数位 |
|---|---|---|---|
| Kp | `kp %f` | 0 ~ 60 | 整数 |
| Ki | `ki %f` | 0 ~ 10 | 0.1 |
| Kd | `kd %f` | 0 ~ 5 | 0.01 |
| Kp2（位置环） | `kp2 %f` | 0 ~ 5 | 0.01 |
| Ki2 | `ki2 %f` | 0 ~ 0.2 | 0.005 |
| Kd2 | `kd2 %f` | 0 ~ 0.2 | 0.005 |
| 限速 ls | `ls %d` | 0 ~ 320 | 整数 |
| 限压 lv | `lv %d` | 0 ~ 25000 | 100 |
| 爬行 lmin | `lmin %d` | 0 ~ 50 | 整数 |
| 遥控死区 dz | `dz %f` | 0 ~ 0.3 | 0.01 |

> 滑条小数位在控件属性里设（"小数位数/精度"）。
> `dz %%` 这类小数参数，滑条值会替换 `%%` 后发出（如 `dz 0.15`），固件的 `atof` 能正常解析。

---

## 四、注意

1. **命令必须用 Str（文本）模式**——Hex 模式的占位符是 `%%` 且按字节流发送，固件解析不了
2. Toggle 开关的关键在**右键 → 发送参数**里设"按下/抬起"两个值；漏设了占位符就不会被替换
3. 波形（JustFloat）与命令发送**互不影响**：一个页面里既看波形又放控件，
   就是"上面波形 + 下面调参"的验收效果
4. 滑条拖动会**连续发送**（拖一下发几十条），固件解析是幂等的，没有副作用
5. 调乱了：点"停止"按钮 → 按 `docs/PID调参指南.md` 第五节一键复位

---

## 五、验收演示建议（面试加分）

调参环节直接用这套：**一边拖滑条改 kp，一边指着 VOFA 波形说"可以看到超调在变大"**——
参数、波形、结论三者实时联动，比"改代码→编译→烧录→再看"的流程有说服力得多。
