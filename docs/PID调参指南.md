# PID 调参指南：看到什么现象，就调哪个参数

> 所有参数都用串口命令改，**改完立刻生效，不用重新编译**。
> 调参前先：`log 1` 开曲线（VOFA 选 JustFloat），`ch0=目标` `ch1=实际` `ch2=输出` `ch3=误差`

---

## 一、先记住双环结构

```
目标角度 ──[位置环 pidAngle]──► 速度目标(限速) ──[速度环 pidSpeed]──► 电压 ──► 电机
    ↑                                                                      │
    └────────────────────── 实际角度 ◄── CAN 反馈 ─────────────────────────┘
```

**铁律：先调好内环（速度），再调外环（位置）。** 内环没调好，外环怎么调都是歪的。

---

## 二、参数总表

| 命令 | 参数 | 作用 | 调太大 | 调太小 |
|---|---|---|---|---|
| `kp` | 速度环 Kp | 决定"追速度有多使劲" | 抖、叫、超调 | 到不了目标速度 |
| `ki` | 速度环 Ki | 消除速度稳态误差 | 超调、积分饱和 | 速度差一点、负载一加就掉速 |
| `kd` | 速度环 Kd | 抑制速度变化过快 | 放大噪声、抖 | 基本不用 |
| `kp2` | 位置环 Kp | 决定"多快冲过去" | 超调、冲过头 | 慢、末端爬行 |
| `ki2` | 位置环 Ki | 消除末端小误差（治爬行） | 超调、到目标后来回摆 | 最后几度到不了 |
| `kd2` | 位置环 Kd | 抑制超调（刹车） | 抖 | 冲过头 |
| `ls` | 内环限速 | 电机最高转速 | 冲太猛 | 转得慢 |
| `lv` | 输出限幅 | 最大电压（力量上限） | 过流/发热 | 带不动、慢 |
| `lmin` | 位置环最小速度 | **抗静摩擦，治末端爬行** | 到目标附近来回蹭 | 最后几度爬不动 |
| `ad` | 位置死区 | 多少度算"到位" | 停不准 | 到位后还在抖 |

## 三、现象 → 诊断 → 处方（核心表）

| 现象 | 原因 | 改什么 |
|---|---|---|
| **开始很快，快到目标时很慢，慢慢爬到最后** | 位置环只有 P：误差小→输出小→速度指令小于静摩擦 | ① `lmin 20`（给最小速度）② `ki2 0.03`（加积分）③ `kp2` 调大一点 |
| **冲过头（超调大）** | Kp2 太大 / Kd2 太小 | `kp2` 减半，或 `kd2 0.05` 往上加 |
| **到位后来回摆动、抖** | Kp2 太大 + Kd2 太小，或死区太小 | 减 `kp2`、加 `kd2`、`ad 1.0` |
| **一直差几度停在那（稳态误差）** | 缺积分 / 有静摩擦 | `ki2 0.02`、把 `lmin` 提到 20 |
| **转得慢吞吞，720° 要走半天** | 限速太小 | `ls 250`（上限 320）、`kp2 2.0` |
| **起步"咯噔"一下很猛** | Kp2 太大 + 没限速软启动 | 减 `kp2`，或降 `ls` |
| **电机抖、叫（高频噪声）** | Kd 太大 / Kp 太大 | 减 `kd`、减 `kp` |
| **速度环跟不到目标速度** | 内环 Kp/Ki 不够或限幅太小 | `kp 40`、`ki 3`、`lv 12000` |
| **负载一加就掉速** | 缺 Ki | `ki 2` 起，逐步加 |
| **720° 转到一半不动了** | 位置环积分饱和 / 限速太小 | 检查 `ls`，`ki2` 别太大 |

## 四、你现在的现象：末端爬行（重点）

**现象**：开始转很快，快到 720° 时很慢才到。

**原因**：纯比例位置环的输出 = Kp × 误差。误差从 720° 降到 5° 时，速度指令从 250rpm 掉到 4rpm，
而电机有**静摩擦**，5rpm 根本推不动 → 就停在那儿慢慢蹭。

**我已经在代码里修好了**（新固件默认就有）：

1. **最小速度 `lmin`**（默认 15rpm）：还有误差但速度指令 < 15rpm 时，直接给 15rpm，推过去
2. **到达死区 `ad`**（默认 0.5°）：误差 < 0.5° 就算到位，直接停
3. **位置环积分 `ki2`**（默认 0.02）：误差长期存在会慢慢加大输出

**如果还爬，按顺序加**：

```
lmin 20        ← 最小速度加大（最常见有效）
ki2 0.05       ← 积分加大
kp2 2.5        ← 比例加大（注意可能超调）
```

**注意**：`lmin` 太大会在目标附近来回蹭（找不到 0.5° 死区），如果开始抖动就把 `ad` 调到 1.0。

## 五、标准调参流程（照做）

### 第 1 步：调速度环（内环）
```
sp 0          ← 先停下
kp 30  ki 2  kd 0
sp 100        ← 阶跃
```
看曲线：快速上升、基本不超调、稳在 100 ± 2rpm → 内环 OK

### 第 2 步：调位置环（外环）
```
zero          ← 角度清零
kp2 1.5  ki2 0.02  kd2 0.03
lmin 15  ad 0.5
an 180        ← 阶跃 180°
```
看曲线：快速转过去、最多超一点点、1~2 秒内稳住

### 第 3 步：多圈验证
```
an 720        ← 转两圈
```
看 `cont` 是否走到 720（±1°），中途不减速卡住

## 六、怎么看指标（验收要写）

| 指标 | 从曲线上怎么读 |
|---|---|
| **超调量** | `(峰值 - 目标) / 目标 × 100%`。如目标 180° 冲到 200° → 超调 11% |
| **响应时间** | 从发命令到进入"目标 ±2%"并**不再出来**的时间 |
| **稳态误差** | 稳定后 `|实际 - 目标|`。180° 停在 179.3° → 稳态误差 0.7° |

**好的曲线长这样**：快速上升 → 轻微超过一点点 → 快速回落 → 稳住不动。
